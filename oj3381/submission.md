## 2. ความเข้าใจโจทย์ของฉัน

เขียนโจทย์ด้วยคำพูดของตนเอง

ให้อธิบาย input, output และ constraints สำคัญด้วย

ถ้ายังไม่เข้าใจโจทย์ทั้งหมด ให้เขียนสิ่งที่เข้าใจในตอนนี้ ความเข้าใจอาจยังไม่ครบหรืออาจผิดได้ แต่ต้องพยายามอธิบายอย่างจริงใจ

```text
โจทย์ให้ฉันเรียงลำดับจุด ตามค่าผลรวม f(x, y) = x + y จากน้อยไปมาก ถ้ามีจุดที่มี x + y เท่ากัน ให้เรียงจุดที่มีค่าพิกัด y มากกว่าขึ้นก่อน

Input:
บรรทัดแรกเป็นจำนวนชุดข้อมูลทดสอบ T
บรรทัดถัดมาระบุจำนวนจุด n
อีก n บรรทัดเป้นเพิกัด
Output:
ให้พิมพ์พิกัด X และ Y ของแต่ละจุดที่จัดเรียงลำดับแล้ว

Constraints:
ค่าพิกัด X และ Y อาจเป็นจำนวนเต็มลบ 0 หรือจำนวนเต็มบวกได้ ซึ่งทำให้ผลรวม x + y มีโอกาสเป็นค่าติดลบ
```

## 3. แผนแรกของฉัน

เขียนแผนแรกก่อนรับความช่วยเหลือจาก AI เพื่อน TA ผู้สอน หรือก่อนสรุป code สุดท้าย

ถ้าใช้ AI ให้เขียนแผนที่มีอยู่ก่อน prompt แรกที่ถาม AI

ถ้าถามเพื่อน TA หรือผู้สอน ให้เขียนแผนที่มีอยู่ก่อนถาม

ถ้าไม่ได้ใช้ AI และไม่ได้ขอความช่วยเหลือจากคน ให้เขียนแผนที่มีอยู่ก่อนหรือระหว่างเริ่มเขียน code

แผนนี้เขียนแบบคร่าว ๆ ได้ อาจยังไม่สมบูรณ์หรืออาจต่างจากวิธีสุดท้าย

สามารถเขียนเป็น pseudocode, flowchart idea หรือขั้นตอนความคิดได้

```text
Step 1: รับค่า T
Step 2: นลูปตามจำนวนชุดข้อมูล T รอบ
Step 3: สร้าง list แยก 3 ตัว ได้แก่ sum_list สำหรับเก็บ x + y , x_list,y_list
Step 4: รับค่าจุด N
Step 5: รับค่า T
Step 6: ลูป n รอบรับค่า x,y คำนวน x+y แล้วแยกเก้บลงในแต่ละ list 
Step 7: วนลูปเปรียบเทียบค่าใน sum_list เพื่อเรียงลำดับจากน้อยไปมาก โดยต้องสลับตำแหน่งข้อมูลใน x_list และ y_list ตามไปด้วย
Step 8:  ถ้าเจอจุดที่ค่าใน sum_list เท่ากัน ให้ไปเปรียบเทียบค่าใน y_list แล้วเช็คเงื่อนไขเพื่อเอาตัวที่ $y$ มากกว่าขึ้นก่อน
Step 9: วนลูปพิมพ์ค่า x และ y จาก list ออกมาทีละคู่

```

## 4. วิธีสุดท้ายที่ใช้จริง

อธิบายสั้น ๆ ว่า algorithm หรือวิธีสุดท้ายที่ใช้จริงใน code ที่ส่งคืออะไร

หัวข้อนี้ต่างจาก Section 3:

- Section 3 คือแผนแรกก่อนใช้ AI ก่อนรับความช่วยเหลือจากคน หรือก่อนเขียน code สุดท้าย
- Section 4 คือวิธีสุดท้ายที่ใช้ใน solution จริง
- ถ้าวิธีสุดท้ายเหมือนกับแผนแรก ให้เขียนว่าเหมือนกัน และอธิบายสั้น ๆ ว่าทำไม

ห้ามคัดลอกคำอธิบายจาก AI

ห้ามคัดลอกคำอธิบายจากคนอื่น

```text
วิธีสุดท้ายของฉันไม่เหมือนกับแผนแรก ในโค้ดจริงฉันเปลี่ยนมาเก็บพิกัดเป็น tuple (x, y) ไว้ใน list เดียวแทนการแยกหลาย list แล้วใช้ฟังก์ชัน sort() ของ Python ร่วมกับ lambda p: (p[0] + p[1], -p[1]) เพื่อเรียงลำดับ   ใส่ -p[1] ช่วยให้ Python เรียงค่า x + y จากน้อยไปมากก่อน แล้วถ้าเท่ากันจะเรียงค่าy จากมากไปน้อยให้อัตโนมัติในบรรทัดเดียว โดยไม่ต้องเขียนลูปเปรียบเทียบและสลับตำแหน่งข้อมูลเองให้ยุ่งยากเหมือนในแผนแรก
```
